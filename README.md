# Quest for Growth

Crie um aplicativo web completo chamado PDI QUEST.

IMPORTANTE:

Não faça apenas um dashboard gamificado.

O produto deve parecer e funcionar como um RPG clássico de exploração, inspirado na sensação de jogos antigos de MMORPG e MOBAs como Ragnarok Online, Perfect World, Dota e League of Legends.

A referência é para:

- sensação de exploração;

- mapa de mundo;

- cidades e vilas;

- NPCs;

- estradas;

- regiões;

- portais;

- construções;

- landmarks;

- progressão;

- missões;

- personagens;

- hierarquia visual;

- sensação de aventura.

NÃO copie personagens, mapas, ícones, assets, UI, nomes de locais ou elementos proprietários desses jogos.

Crie uma identidade visual completamente original para o PDI QUEST.

========================================

1. OBJETIVO DO PRODUTO

========================================

O PDI QUEST é uma camada de RPG sobre o Programa de Desenvolvimento Individual de Design da Eiaye.

O jogo NÃO é o produto principal.

O jogo é o instrumento.

O objetivo é transformar desenvolvimento profissional em uma experiência de exploração, progressão e descoberta.

Princípios:

Aprender melhor → criar melhor → decidir melhor.

O sistema deve tornar desenvolvimento observável sem transformar o processo em cobrança, ranking ou prova tradicional.

Não criar:

- ranking público;

- competição entre pessoas;

- leaderboard;

- sistema de punição;

- prazo obrigatório;

- avaliação subjetiva de gestor.

A experiência deve recompensar exploração, consistência e desenvolvimento.
